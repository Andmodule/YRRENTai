# Страница настроек (account settings)

## Цель

Структурировать `/settings`: вложенная навигация только на этой странице (не глобальный sidebar), отдельный URL на раздел, перенос Telegram в «Уведомления».

## Реализованные решения

1. **Навигация** — тот же визуальный паттерн, что глобальный sidebar (`frontend-user/src/components/layout/sidebar.tsx`): `Link` из `@/i18n/navigation`, активное состояние `bg-primary/15 text-primary border border-primary/20`, неактивное `text-slate-400 hover:bg-slate-800 …`. Дополнительно у активного пункта **левая полоса** `border-l-2 border-l-primary`. Desktop: колонка ~220px; mobile: горизонтальный скролл тех же пунктов.

2. **Карточки** — семантика темы: `bg-card rounded-xl border p-6` (не привязка к «белому» в тёмной теме).

3. **Роутинг** — вложенные сегменты App Router:
   - `/settings` → редирект на `/settings/profile`
   - `/settings/profile`, `security`, `notifications`, `integrations`, `ai`, `billing`, `team`

4. **Роли** — нормализация `user.role` из API в нижний регистр (`OWNER` → `owner`). Матрица:
   - **owner** — все разделы
   - **manager** — профиль, безопасность, уведомления, ИИ; прямой заход на `integrations` / `billing` / `team` → редирект на профиль
   - **staff** — нет доступа: редирект на `/dashboard`
   - Роли вне списка обрабатываются как **owner** (полное меню), чтобы не скрывать настройки при новых значениях API.

5. **Команда (team)** — бэкенда списка сотрудников пока нет; страница и модалки — UI-заглушка под будущий API.

6. **Тег `dev`** — у пунктов меню и заголовков разделов, где функциональность ещё не готова / нет API, показывается бейдж **`dev`**, чтобы при разработке было видно незавершённые блоки. Раздел «Уведомления» без тега на ссылке (рабочий блок Telegram); подсекции email и порог эскалации помечены `dev` внутри страницы.

## Готовность по API (v1)

| Раздел        | Состояние |
|---------------|-----------|
| Профиль       | Форма UI; сохранение профиля на бэкенде не подключено — `dev` |
| Безопасность  | Заглушки — `dev` |
| Уведомления   | **Telegram Chat ID** — `PATCH /users/me/telegram`; остальное — `dev` |
| Интеграции    | Заглушки — `dev` |
| ИИ-ассистент  | Локальное состояние — `dev` |
| Тариф         | Заглушки — `dev`, только owner |
| Команда       | Заглушки — `dev`, только owner |

## Оболочка приложения

`[locale]/settings/layout.tsx` оборачивает детей в `AppShell` (как `bookings`, `properties`, `chat`).

## Out of scope (как ранее)

Реальный биллинг, реальный 2FA, смарт-замки с API, push в браузере.
